## Getting Started

Welcome to the ad-metrics exporter! This powerful and flexible tool makes it easy to seamlessly export your campaign metrics. To get up and running, you'll first need to ensure that you have Python 3.11 or newer available on your machine as well as access to the `ads-prod` GCP project, and once that's in place you can go ahead and create a virtual environment with `python -m venv .venv` and activate it using `source .venv/bin/activate`, after which the dependencies can be installed by running `pip install -r requirements.txt`. Before running the exporter for the first time, it's important to authenticate by running `gcloud auth application-default login`, and you'll also want to copy `config.example.toml` to `config.toml` and update the `dataset` value, keeping in mind that pointing it at `ads_prod` instead of `ads_sandbox` will result in the exporter overwriting the live reporting tables, so be careful with that. Finally, the exporter can be launched via `python -m exporter run --date 2026-03-01`, which should take roughly 10 minutes to complete.
